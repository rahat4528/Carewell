# Carewell Technology Stack

Carewell utilizes modern, enterprise-grade open-source technologies across each independent application.

| Layer | Technologies Selected | Rationale & Use Case |
|---|---|---|
| **Frontend Framework** | **Next.js 14+ / React 18+** | Server-side rendering (SSR), static optimization, robust routing, and optimal web performance across desktop, tablet, and mobile devices. |
| **Styling & Components**| **Tailwind CSS & Modern Accessible UI** | Fast styling, responsive design primitives, high contrast ratios, and WCAG-compliant interface components. |
| **Data Visualization** | **Recharts** | Declarative charting for progressive overload trends, vitals history, and occupancy tracking. |
| **Backend Framework**  | **NestJS (TypeScript)** | Modular architecture, strict dependency injection, built-in validation pipes, OpenAPI/Swagger documentation, and structured microservice readiness. |
| **ORM & Data Layer**   | **Prisma ORM** | Type-safe database queries, schema migrations, strict relation modeling, and transactional guarantees. |
| **Database**           | **PostgreSQL 16** | ACID transactions, row-level locking, foreign key constraints, partial indexes, and JSONB capabilities. |
| **Caching & Queues**   | **Redis & BullMQ** | Fast in-memory cache, rate limiting, and robust job queue orchestration for reminders and data synchronization. |
| **File Storage**       | **S3 API / MinIO** | Object storage with pre-signed URL generation and server-side encryption. |
| **Testing**            | **Jest & Supertest** | Comprehensive unit testing of calculation logic, integration tests for APIs, and role-based security validation. |
| **Containerization**   | **Docker & Docker Compose** | Reproducible development, isolated service boundaries, and local service orchestration. |
